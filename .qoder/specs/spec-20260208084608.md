# Web 音乐播放器 - 技术方案与开发计划

## 技术栈

| 类别 | 选型 |
|------|------|
| 框架 | React 18 + TypeScript |
| 构建 | Vite 5 |
| 样式 | Tailwind CSS 3 |
| 状态管理 | Zustand（轻量、支持持久化） |
| 图标 | lucide-react |
| 音频元数据 | jsmediatags（ID3标签解析） |
| 颜色提取 | colorthief（封面主色调） |
| 工具 | clsx + tailwind-merge |

## 设计规范

- 深色主题，主色 `#00ff88`（科技绿），背景 `#1a1a1a`
- 毛玻璃卡片、径向渐变背景、发光阴影
- 字体：中文微软雅黑，英文 Arial
- 动画 `0.3s ease`，圆角 `8-15px`

## 数据来源

- 用户本地导入音频文件（mp3等），通过 FileReader + jsmediatags 解析元数据和封面
- 同名 LRC 文件自动匹配歌词
- 预留 API 接口扩展能力

## 核心架构设计

### 1. 音频引擎（AudioEngine.ts）

基于 HTML5 Audio API 的单例引擎：
- 播放/暂停/seek/音量控制
- 事件监听同步到 Zustand store（timeupdate、ended、error）
- 循环模式处理（列表循环/单曲循环/随机）
- 自动播放限制引导（首次交互后播放）

### 2. 状态管理（Zustand）

**playerStore** - 播放状态（isPlaying、currentTime、duration、volume、loopMode、quality）
**playlistStore** - 队列和收藏（playlist、favorites、userPlaylists），持久化到 localStorage
**settingsStore** - 用户偏好，全部持久化

### 3. LRC 歌词解析

- 正则解析 `[mm:ss.xx]` 时间戳
- 同时间戳行合并为翻译（中英双语）
- 二分查找当前行，scrollTo 保持在容器 1/3 位置
- 当前行科技绿高亮 + 放大，其余行半透明

### 4. 本地文件导入

- `<input type="file" accept="audio/*" multiple>` + 拖拽上传
- jsmediatags 解析 ID3 标签（歌名、歌手、专辑、封面）
- `URL.createObjectURL` 生成音频/封面 URL
- 同名 `.lrc` 文件自动关联

### 5. 动画方案

| 动画 | 方案 |
|------|------|
| 唱片旋转 | CSS `animation: spin 20s linear infinite` + `animation-play-state` |
| 唱针 | CSS `transition: transform 0.6s cubic-bezier` |
| 背景渐变 | `transition: background 1s ease` + colorthief 提取色 |
| 歌词滚动 | `scrollTo({ behavior: 'smooth' })` |
| 收藏心跳 | CSS `@keyframes heartbeat scale(1.2)` |
| 所有动画 | `will-change: transform` GPU 加速 |

## 验证方式

1. **开发阶段**：每个 Sprint 完成后用 MCP 浏览器工具打开页面验证
2. **P0 验收**：播放/暂停 ≤500ms、切歌 ≤1s、进度拖拽 ≤300ms、歌词同步 ≤200ms、动画 60fps
3. **兼容性**：Chrome / Firefox / Safari / Edge 最近 3 个版本
4. **性能**：首屏 ≤3s、CPU ≤15%
5. **持久化**：刷新后音量、循环模式、收藏恢复
